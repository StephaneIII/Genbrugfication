# API

Minimal TypeScript + Express API scaffold.

## Scripts

- `npm run dev` starts the API in watch mode.
- `npm run build` compiles TypeScript into `dist`.
- `npm start` starts the compiled API.

## Default endpoint

- `GET /health` returns API status.

## Basic structure

- `src/routes` for route registration
- `src/controllers` for request handlers
- `src/middleware` for shared middleware
